# Telangana-Weather-Analysis-PowerBI
Interactive Power BI dashboard analysing Telangana weather trends with insights into temperature, rainfall, humidity, wind speed, and seasonal patterns using Power Query and DAX.


## Overview

This project analyses historical weather data of Telangana using Power BI. The dashboard provides interactive insights into rainfall, temperature, humidity, wind speed, seasonal patterns, and yearly trends to support data-driven weather analysis.

---

## Project Objective

- Analyse historical weather trends.
- Compare weather conditions across multiple years.
- Identify seasonal rainfall and temperature patterns.
- Build an interactive dashboard for decision-making.

---

## Tools Used

- Power BI
- Power Query
- DAX
- Microsoft Excel

---

## Dataset

The dataset contains monthly weather observations organised year-wise.

Features include:

- Date
- Maximum Temperature
- Minimum Temperature
- Average Temperature
- Rainfall
- Humidity
- Wind Speed
- Season
- Year
- Month

---

## Dashboard Features

- KPI Cards
- Rainfall Analysis
- Temperature Analysis
- Seasonal Comparison
- Wind Speed Analysis
- Humidity Analysis
- Monthly Trends
- Yearly Trends
- Interactive Filters

---

## Key Insights

- Seasonal rainfall trends.
- Temperature variations throughout the year.
